# Customer case study template (unpublished)

Use only with a real customer's written approval. Keep hypothetical examples out of this format:
an illustration belongs on a feature page, labelled as an example, never as a case study.

## 1. Customer context
- Business name (or "a US wholesale seller" if they prefer), approval to name: yes / no
- Business model: wholesale / mixed; years selling; marketplaces
- Size band they are happy to publish (e.g. "under $50K a month"), never an exact figure without approval
- Apex plan and start date

## 2. The operational problem
One paragraph in their words. What was slow, error-prone or invisible?

## 3. How they worked before
Tools, spreadsheets, people, and roughly how long the key task took.

## 4. What they use in Apex
Modules and features actually used (check in the account, do not guess): e.g. UPC Scanner, purchase
orders, P&L, Review Booster, AI connector.

## 5. Measurement period
Start and end dates. Same season where possible.

## 6. Results
Pick measurable ones and record how each was measured:

| Measure | Before | After | How measured |
|---|---|---|---|
| Time to evaluate one supplier catalog | | | e.g. timed by the seller on two comparable catalogs |
| Time to prepare a purchase order | | | |
| Time to find products that need restocking | | | |
| Duplicate data entry (systems a cost is typed into) | | | |

## 7. Method and limitations
What else changed in the period (new suppliers, season, ad spend)? What can and cannot be
attributed to Apex? Say so plainly.

## 8. Approved quotation
Exact words, with the date the customer approved them and where (email link on file).

## Publishing checklist
- [ ] Written approval on file for name, figures and quote
- [ ] Every figure traced to a source the customer agreed to
- [ ] No revenue or profit claim presented as typical
- [ ] Reviewed date on the page
